# 快速使用

## 先体验一套完整方案

1. 打开“养成规划”，点击“载入25时示例”。
2. 点击上方任一成员，设置该卡当前和目标的等级、特训、专家等级、技能等级、剧情与装饰画。
3. 展开“区域道具”，设置当前等级与目标等级；普通同团和同属性五人加成会自动判断。
4. 需要时展开“角色等级与称号”和“MySEKAI大门与家具”。
5. 在材料清单的“已持有”一栏填写库存，缺口会立即更新。
6. 点击“导出精美报告”，选择配色并生成预览，再下载PNG。
7. 点击“保存方案”，或导出JSON，便于下次继续修改。

`examples/Team-Plan.json` 也可通过“导入JSON”载入。同一文件对应的实际导出报告是 `examples/Team-Report.png`。

## 计算一张卡牌

在图鉴中打开卡牌，点击“单卡养成计算”；或者在养成规划中切换“单张卡牌”，然后选卡。

单卡和五人模式分别保存草稿。单卡计算没有完整同组合／同属性的五人加成；想观察该效果时应建立五人编组。

## 查看和播放谱面

1. 打开“谱面研究室”，搜索歌曲名、作者或ID。
2. 选择国服已经开放的难度。
3. 动态模式下，点击播放；可调节音符流速与播放速度，并拖动进度条。
4. 音频不同步时可调整“校准偏移”，程序已自动计入歌曲开头留白。
5. 静态模式下可以缩放、切换底色，并下载完整谱面PNG。

首次可以使用 Tell Your World 的 EXPERT／MASTER，或搜索“2”选择ROKI体验内置音源和谱面。其他资源需要联网读取。

## 查卡面

在“卡牌图鉴”中检索并打开卡牌，选择特训前或特训后；“高清卡面”保存原图，“资料卡PNG”导出带卡牌信息的排版图片。卡面切换只用于浏览，不会更改培养方案的特训状态。


## 把卡面和音源下载到本地

在项目根目录运行 `python scripts/download_assets.py`（Python 3.8+，无需 pip）。
可先运行 `python scripts/download_assets.py --dry-run` 查看数量。下载后刷新网页即可
优先读取项目内文件；资源设置中可勾选「仅使用本地资源」。详细筛选、续传与离线
启动说明见 [OFFLINE_ASSETS.md](OFFLINE_ASSETS.md)。
