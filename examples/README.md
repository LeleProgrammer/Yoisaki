# 示例方案与图片

- `Team-Plan.json`：在实际网页中配置并导出的国服五人队伍示例。
- `Team-Report.png`：上述方案由实际网页导出的 1800 像素宽 PNG，不是手工绘制的静态宣传图。
- `Card-Report.png`：卡牌 #1253 的实际导出资料卡，包含原始技能与特训追加技能。
- `Static-Chart.png`：Tell Your World / EXPERT 的实际完整谱面导出。

可在“养成规划 → 导入 JSON”中导入示例，修改卡牌、专家等级、装饰画、区域道具和库存后再次生成报告。示例金币库存设置为 1,000,000，只用于展示缺口扣减，不代表任何真实账号。
